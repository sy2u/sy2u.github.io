# Blog 管理

总入口 `/blogs/`；论文目录 `/blogs/paper-reading/`。
页面沿用主页风格，不显示个人资料，首页导航没有博客入口。
博客带有 `noindex`，并从 sitemap、RSS 排除；公开页面仍可通过链接访问。

## 文章存放与发布

每篇文章使用独立目录，包含 `index.html` 和全部图片、附件：

- 本地：`blogs/local/paper-reading/<英文短名>/`
- 公开：`blogs/public/paper-reading/<英文短名>/`

`blogs/local/` 被 Git 忽略，没有 Git 备份。未公开稿件的解析保存在本地。
Jekyll 自动扫描文章，本地预览显示两处内容；远程从 Git checkout 构建，
只生成 public 中的文章。列表只显示标题和一句话梗概，按日期倒序排列。

公开一篇文章时，将整个目录移到 public 对应位置，再提交、推送。
文章 URL 随目录变化。已提交的内容即使移回 local，Git 历史仍保留副本。
发布使用 Git checkout 构建，不上传包含本地文章的本机 `_site/`。

## 添加文章

直接创建 `index.html`，开头填写 YAML 元数据，之后写 HTML 正文。
现有公开文章可供参考，无需复制固定章节骨架。

- `title`：论文标题。
- `date`：笔记日期，用于排序及文章内显示。
- `blog_category: paper-reading`：所属 Blog。
- `listing_summary`：仅显示在目录的一句话梗概。
- `paper_url`：可选的论文原文链接。
- `published: true`：参与页面渲染；false 为草稿。是否进入 Git 由所在目录决定。

正文使用 HTML 片段，布局提供标题、导航、日期与原文链接。
保留默认 layout、permalink、sitemap 设置。资源放在本篇目录，使用
`{{ page.url | append: 'figure-01.png' | relative_url }}` 引用，以便整目录迁移。
本地文章的附件也须留在 local 下。

## 内容与排版

- 按论文实际内容解释背景、问题、机制、公式、实验和结论。关键概念首次出现时
  补充必要背景；公式说明变量、单位和假设。明确区分原文结论、阅读推断与待验证问题。
- 原文章节编号放在标题前，例如“§1–4 背景与动机”。页码写在标题下方：
  `<p class="section-source">PDF p. 1–3</p>`。图表、公式或附录出处可放在同一行。
- 如需阅读声明，使用 `<p class="blog-disclaimer">...</p>`；统一显示为灰色小字。
- arXiv 论文先检查源码包中的原图。原图不可用时，从 PDF 提取或渲染；
  检查文字、坐标轴、边框完整，不使用 AI 重绘代替原图。
- 图片使用 `figure`、可点击的 `a`、带 alt/实际尺寸的 `img` 和 `figcaption`。
  图注说明图号、内容和原论文 PDF 页码；附近正文解释如何读图及结论范围。
- 共享样式已提供图片居中、图注居中和自适应宽度。宽图可用 `figure.reading-wide`；
  表格外包 `div.reading-table` 以支持横向滚动，不要在文章中重复这些样式。
- 字体、配色沿用主页。额外交互的 CSS 限定在自己的容器内，兼顾键盘和小屏幕。
  站点已加载 MathJax 2，支持 `$...$`、`$$...$$`，不要重复加载。
- 正文中的 Liquid 示例字面量需用 raw/endraw 包裹，避免被 Jekyll 执行。

## 重要写作守则：有话直说

- 精简通过选择值得保留的内容来完成。删去重复讨论和次要案例，保留关键概念、
  因果关系与必要的解释，避免把段落压成难懂的结论或术语。
- 实验方法是阅读重点：讲清要确认什么、如何设置实验与对照、观察到什么，
  以及这些观察支持什么判断。围绕选中的实验展开，无需逐节覆盖整篇论文。
- 尽量避免“不是……而是……”“并非……而是……”等先否定再转折的句式。
  直接说明对象是什么、机制如何工作、证据支持什么结论。
- 不替读者设定误解，不虚构一个假设或错误观点作为铺垫。
  避免无来由的“不能保证”“不意味着”“不能理解成”等表达。
- 避免防御性写作。示例、符号和上下文已经清楚时，不添加“仅作示意”等
  多余声明；限定说明应解决实际歧义或交代影响结论的证据边界。
- 用具体的因果关系连接句子：写明条件、动作和结果，减少“另一方面”
  “更值得注意”等缺乏实质内容的过渡。
- 数据的单位、统计范围、实验条件与证据边界应直接说明。
  保留真实的方案对比、性能权衡和必要的限制，不为简化表达删掉技术含义。
- 审核时通读段落的论证关系，检查每个转折是否有事实依据；
  优先重写整个句子，不仅替换连接词。

## 本地预览

运行 `./run_server.sh`，访问 `http://127.0.0.1:4000/blogs/`。
可通过 `--host 127.0.0.1 --port 4010` 指定地址和端口。

## 添加其他 Blog

在 `_pages/blogs/` 下创建分类页面，填写 `title`、`permalink`、`blog: true`
和分类键 `blog_key`。正文调用 `{% include blog-entries.html category=page.blog_key %}`。
新文章放入 local/public 下对应的分类目录，`blog_category` 填写同一分类键。
总目录、文章列表和返回分类链接会自动生成。
